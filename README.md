The one line an AI agent prints the moment it breaks production — a brutally honest confession, no hedging, no corporate euphemism: it pushed an untested migration, dropped the users table, and the backup was on the same disk it just wiped. "My deploy, my outage."

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), after self-checking the house gate: UTF-8, one line, 1–200 characters, not whitespace-only.
